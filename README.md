# Измерение скорости скачивания

Консольный скрипт на Python 3.8+ без сторонних зависимостей.

## Запуск

Сохраните `internet_speed.py`, откройте терминал в папке с файлом и выполните:

```shell
python internet_speed.py "https://example.com/image.jpg"
```

Замените адрес на прямую HTTP(S)-ссылку на существующий файл, например большую картинку. В Windows вместо `python` также можно использовать `py`.

Тайм-аут сетевых операций по умолчанию — 30 секунд. Его можно изменить:

```shell
python internet_speed.py "https://example.com/image.jpg" --timeout 60
```

## Что делает скрипт

1. Выполняет ровно 10 последовательных GET-запросов к указанному адресу.
2. В каждом запросе полностью читает тело ответа порциями, не сохраняя файл на диск.
3. Измеряет время от начала запроса до окончания чтения ответа, включая подключение и ожидание сервера.
4. Выводит среднее время запроса, суммарный объём и скорость скачивания.

Скорость = сумма скачанных байтов / сумма времени всех 10 запросов.

Единицы: MB — 1 000 000 байтов; MB/s — мегабайты в секунду; Mbit/s — мегабиты в секунду (1 байт = 8 бит). Объём включает тела ответов, но не HTTP-заголовки и служебный сетевой трафик.

Результат показывает скорость скачивания с выбранного сервера и зависит от его ограничений, задержки и размера файла. Это не гарантированная пропускная способность интернет-канала. Один файл скачивается 10 раз, поэтому учитывайте расход трафика.

При ошибке запросов скрипт останавливается с кодом 1 и не печатает итог по неполному набору измерений. Ctrl+C завершает работу с кодом 130. Тайм-аут применяется к блокирующим сетевым операциям, а не ко всему времени скачивания.
